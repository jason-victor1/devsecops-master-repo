# Enterprise Security Policy & Vulnerability Reporting

## Security Commitment

We enforce strict least-privilege zero-trust architectures across all supply-chain, compute, and data layers.

## Reporting Security Vulnerabilities

If you discover a potential security flaw, misconfiguration, or secret exposure, do **NOT** file a public issue.

Submit a PGP-encrypted report directly to:
**`security-operations@enterprise.local`**

### Vulnerability Response SLA

| Severity     | Initial Response | Remediation SLA    |
| :----------- | :--------------- | :----------------- |
| **CRITICAL** | < 2 Hours        | < 24 Hours         |
| **HIGH**     | < 8 Hours        | < 72 Hours         |
| **MEDIUM**   | < 24 Hours       | < 7 Business Days  |
| **LOW**      | < 48 Hours       | Next Release Cycle |
